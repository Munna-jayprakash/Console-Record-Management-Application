Console Record-Management Application

A menu-driven console application built in Python for managing records (Add, View, Search, Update, Delete) with persistent storage using File I/O.)

Features
>Menu-driven interface — simple numeric menu for navigation
> Add Record — create new records with validated input
> View Records — display all stored records
> Search Record — find a record by ID/name
> Update Record — modify existing record details
> Delete Record — remove a record permanently
> File I/O — records persist in a file (records.json) even after the program closes
> Exception Handling — handles invalid inputs and file errors
#Tech Stack
Language: Python 3.x
Concepts used: Data Types & Variables, Conditionals & Loops, Functions, Exception Handling, File I/O
#Project Structure
